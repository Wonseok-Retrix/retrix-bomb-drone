# 01. 하드웨어 준비 및 배선

## 부품

| 구분       | 부품                                   | 비고                      |
| -------- | ------------------------------------ | ----------------------- |
| 비행 컨트롤러  | MicoAir 743 v2                       | ArduPilot Copter 펌웨어 탑재 |
| 컴패니언 컴퓨터 | Raspberry Pi **Zero W**              | Zero 2 W도 사용 가능         |
| 카메라      | Raspberry Pi AI Camera (Sony IMX500) |                         |
| 케이블      | 22핀(미니) ↔ 15핀 CSI 변환 케이블             | Zero 계열 전용 미니 커넥터 사용    |
| 드로퍼      | 마이크로 서보 (SG90 등) + 투하 기구물            | 2일차 과녁 자동 투하용           |
| 배선       | 4핀 JST-GH (TELEM2용), 듀폰 점퍼           |                         |

## Zero W로 충분한 이유

* Raspberry Pi Zero W는 매우 작고 가벼운 경량 컴패니언 컴퓨터입니다.
* Zero W 자체는 프로세서 사양이 낮아 복잡한 AI 연산을 직접 수행하기 어렵습니다.
* 하지만 신경망 추론 연산은 **AI 카메라 내부(IMX500 칩)** 에서 전담하여 처리합니다.
* 따라서 Zero W는 카메라에서 전달받은 바운딩 박스 좌표로 제어 명령을 계산하고, 이를 MAVLink로 비행 컨트롤러에 전송하는 역할만 수행하므로 충분히 활용 가능합니다.

| 항목      | 선택                                 | 이유                         |
| ------- | ---------------------------------- | -------------------------- |
| OS      | 32비트 Bookworm **Lite**             | 512MB RAM 환경, 데스크톱 환경 불필요 |
| 영상 처리   | **PIL + simplejpeg** (OpenCV 미사용)  | 무거운 OpenCV 대신 가벼운 라이브러리 활용 |
| 화면 확인   | **브라우저** `http://drone.local:8080` | Lite 버전에 데스크톱 미포함            |
| GPU 메모리 | `gpu_mem=64`                       | 헤드리스 운영 최적화                    |

작업 목적에 맞춰 프레임레이트를 나누어 설정합니다.

| 작업            | 설정                                 |
| ------------- | ---------------------------------- |
| 화면 보며 튜닝 (지상) | `python3 tools/preview.py --fps 2` |
| 실비행           | `camera.fps: 12`, preview 실행 안 함   |

비행 중에는 화면 출력(미리보기)을 하지 않으므로 CPU 부담이 적습니다.
카메라 fps를 낮추더라도 MAVLink 명령은 `config.yaml`에 설정된 `send_rate` 주기에 맞춰 차질 없이 전송됩니다.

> 세팅을 완료한 후 `python3 tools/check_camera.py`를 실행하여 실측 fps가 **10 이상** 나오는지 반드시 확인하세요.

## 배선 1: 카메라

* 22핀 미니 CSI 케이블을 사용하여 AI 카메라를 Raspberry Pi Zero W의 카메라 커넥터에 연결합니다.
- 케이블의 금색 접점이 **보드 방향(아래쪽)** 을 향하도록 꽂아주세요.
- **주의:** Zero 계열은 일반적인 15핀 커넥터가 아닌 **22핀 미니 커넥터**를 사용합니다.

## 배선 2: Pi ↔ 비행 컨트롤러 (MAVLink)

MicoAir 743 v2의 **TELEM2 (SERIAL4)** 포트를 사용합니다.

```
   MicoAir 743 v2 TELEM2            Raspberry Pi Zero W
   ─────────────────────            ───────────────────
     5V   ───────────────────────►  물리핀 4  (5V)
     TX   ───────────────────────►  물리핀 10 (GPIO15 / RXD)
     RX   ◄───────────────────────  물리핀 8  (GPIO14 / TXD)
     GND  ───────────────────────   물리핀 6  (GND)
```

**주의: TX와 RX는 반드시 교차(Cross)** 하여 연결해야 합니다. 가장 흔히 발생하는 실수이므로 주의하세요.

> Zero W는 블루투스 모듈이 기본 하드웨어 UART(PL011)를 점유하고 있어,
> 그대로 두면 GPIO 14/15 핀에 보드레이트가 불안정한 mini UART가 할당됩니다.
> `tools/install.sh` 실행 시 블루투스를 비활성화하여 PL011을 GPIO로 되돌리며,
> 이후 `/dev/serial0` 포트로 접속하게 됩니다. 
> 자세한 내용은 [03. 시리얼 포트](03-flight-controller.md#3-시리얼-포트-pi-연결) 섹션을 참고하세요.

## 배선 3: 서보 드로퍼 (과녁 투하용, 2일차)

서보 드로퍼는 **비행 컨트롤러(FC)의 제어를 거치지 않고**, 라즈베리파이가 신호 핀으로 직접 제어합니다.
전원은 FC의 서보 레일에서 5V를 공급받습니다.

```
   FC 서보 레일 (또는 5V BEC)        서보              Raspberry Pi
   ─────────────────────────        ────              ────────────
     5V   ─────────────────────►  빨강 (VCC)
     GND  ─────────────────────►  갈색 (GND) ─────►  물리핀 6  (GND)
                                  주황 (신호) ◄────  물리핀 12 (GPIO18)
```

- **접지(GND)는 반드시 FC, 서보, 라즈베리파이 3자가 모두 공통으로 연결**되어야 합니다.
  접지가 분리되면 서보가 작동하지 않거나 오작동(떨림)이 발생합니다. 가장 흔한 실수입니다.
- **서보 전원을 라즈베리파이의 5V 핀에서 직접 뽑지 마세요.** 서보 구동 시 순간 전류로 인해
  라즈베리파이가 재부팅될 수 있습니다. 전원은 FC 서보 레일이나 별도의 BEC에서 받으세요.
- MicoAir 743 v2의 서보 레일은 **외부 BEC가 연결되어 있어야 5V 전원이 출력됩니다.**
  멀티미터(테스터기)로 5V 전압이 실제로 출력되는지 사전에 측정해 보세요.
- 신호선은 `config.yaml`의 `dropper.pin` 설정과 일치해야 합니다 (기본값: GPIO18).

작동 확인:

```bash
python3 tools/check_dropper.py
```

## 조립 시 주의사항

- **카메라는 아래쪽을 향하도록 장착**합니다. 지상의 목표물을 감지해야 합니다.
- 카메라 CSI 케이블은 파손되기 쉬우므로 프로펠러나 모터의 회전부와 간격을 두고 견고하게 고정해야 합니다.
