# 02. 라즈베리파이 세팅

## 1. OS 굽기

[Raspberry Pi Imager](https://www.raspberrypi.com/software/) 프로그램에서 아래 항목을 설정합니다:

- 기기: **Raspberry Pi Zero W**
- OS: **Raspberry Pi OS Lite (32-bit)** — Bookworm
  - 데스크톱 버전이 아닌 **Lite** 버전을 선택하세요. 화면은 브라우저를 통해 확인합니다.
  - Zero 2 W를 사용하는 경우 64비트 Lite 버전을 선택하셔도 무방하며, 이외 설정은 동일합니다.
- ⚙️ **설정(OS 맞춤설정)** 버튼을 눌러 다음 항목을 미리 설정합니다:
  - 호스트명: `drone` (네트워크 접속 주소: `drone.local`)
    - **팀이 여러 개라면 `drone01`, `drone02`와 같이 다르게 지정해 주세요.** 동일한 네트워크에 같은 호스트명이 존재하면 `.local` 주소 충돌이 발생합니다.
  - 사용자 이름 및 비밀번호 설정 (예: `pi`)
  - Wi-Fi SSID 및 비밀번호 입력 — **반드시 2.4GHz 대역이어야 합니다.** (Zero W 및 Zero 2 W는 5GHz Wi-Fi를 지원하지 않습니다)
  - **SSH 사용** 옵션 체크

## 2. 접속

```bash
ssh pi@drone.local
```

## 3. 설치

```bash
sudo apt install git
git clone <이 저장소 주소> ~/ai-tracking-drone
cd ~/ai-tracking-drone
bash tools/install.sh
sudo reboot
```

`install.sh` 스크립트의 주요 수행 작업:

| 패키지                                                      | 내용                                                      |
| -------------------------------------------------------- | ------------------------------------------------------- |
| `imx500-all`                                             | AI 카메라 펌웨어 + 기본 모델(`/usr/share/imx500-models/`) + 패키징 도구 |
| `python3-picamera2`, `python3-simplejpeg`, `python3-pil` | 카메라 구동 및 영상 렌더링 (apt 패키지로 설치)                        |
| `python3-opencv`                                         | picamera2 의 IMX500 모듈이 import 시점에 요구하는 의존성                |
| `python3-pymavlink`, `python3-yaml`                      | 비행 컨트롤러 통신 및 설정 파일 읽기                                   |
| `dtoverlay=disable-bt`                                   | 블루투스를 비활성화하여 안정적인 하드웨어 UART를 GPIO 핀으로 되돌림               |
| raspi-config                                             | UART 활성화 및 시리얼 로그인 콘솔 비활성화                            |
| `gpu_mem=64`                                             | 헤드리스 운영 환경에 최적화된 메모리 확보                               |

## 4. 카메라 확인

```bash
cd ~/ai-tracking-drone
python3 tools/check_camera.py
```

**처음 실행 시 1~2분간 대기 상태가 유지될 수 있습니다.** 이는 카메라에 AI 모델 펌웨어를 업로드하는 과정입니다.
펌웨어 업로드가 정상적으로 완료되면 다음과 같은 로그가 출력됩니다:

```
[11.8 fps] person x1, chair x2        | 최고: person 0.83 box=(210, 95, 180, 340)
```

카메라 감지 범위 안에 사람이 서면 `person` 라벨이 정상적으로 감지되어야 합니다.

**출력 왼쪽의 실측 fps를 확인하세요.** 설정값(기본 12)과 유사해야 합니다.
실측 fps가 10 미만으로 떨어지면 비행 중 추적 성능이 불안정해질 수 있습니다.
자세한 내용은 [04. 프레임레이트](04-flight-and-tuning.md#프레임레이트-camerafps) 섹션을 참고하세요.

### 문제 해결 (동작하지 않을 때)

| 증상                                           | 확인 및 조치 사항                                               |
| -------------------------------------------- | -------------------------------------------------------- |
| `No cameras available`                       | CSI 케이블 체결 상태 및 방향 확인. `rpicam-hello --list-cameras`로 점검 |
| `imx500-models` 없음                           | `sudo apt install imx500-all` 재실행                        |
| `ModuleNotFoundError: No module named 'cv2'` | `sudo apt install -y python3-opencv` (설치에 5~10분 소요)      |
| 계속 멈춰 있음                                     | 전원 공급 부족. 정품 5V 전원 어댑터로 직접 급전하여 재시도                      |
| 검출은 되지만 응답이 느림                               | `config.yaml`의 `camera.fps` 값을 10으로 하향 조정                |

## 5. 브라우저를 통한 실시간 모니터링 및 튜닝

라즈베리파이 터미널에서 다음 명령을 실행하세요:

```bash
python3 tools/preview.py --fps 2
```

동일한 네트워크에 연결된 노트북이나 스마트폰 브라우저에서 아래 주소로 접속합니다:

```
http://drone.local:8080
```

- 초록색 박스: 감지된 모든 물체
- 빨간색 박스: 현재 지정하여 추적 중인 목표물
- 세로 회색 영역: 데드밴드 (Deadband, 목표물이 이 영역 내에 있으면 회전 제어를 수행하지 않음)
- 하단 빨간색 텍스트: 현재 비행 컨트롤러로 전송되는 계산된 속도 제어 명령

`config.yaml` 파일의 파라미터를 수정하고 재실행하면서 제어 반응을 확인해 보세요.

### 접속 조건

라즈베리파이와 노트북이 **동일한 Wi-Fi 네트워크(같은 공유기)** 에 연결되어 있어야 접속할 수 있습니다.
웹 서버는 모든 네트워크 인터페이스(`0.0.0.0:8080`)에 대해 수신 대기하며, Bookworm Lite 기본 환경에는 별도의 방화벽이 설정되어 있지 않습니다.

### 문제 해결 (접속이 되지 않을 때)

| 증상                         | 원인                              | 해결 방안                                                        |
| -------------------------- | ------------------------------- | ------------------------------------------------------------ |
| Pi가 Wi-Fi에 연결되지 않음         | 공유기가 5GHz 전용인 경우                | 2.4GHz 대역을 활성화하세요. Zero 계열은 5GHz를 지원하지 않습니다                  |
| `drone.local` 접속 불가        | mDNS 미지원 (안드로이드, 구형 윈도우)        | Pi에서 `hostname -I`로 IP를 확인한 후 `http://192.168.x.x:8080`으로 접속 |
| 동일한 호스트명의 Pi가 여러 대 존재하는 경우 | `.local` 이름 충돌 발생               | 팀마다 호스트명을 다르게 지정하세요 (`drone01`, `drone02` 등)                 |
| SSH 접속은 되지만 브라우저 접속만 안 됨   | 공유기의 **클라이언트 격리(AP isolation)** | 게스트 네트워크 대신 일반 네트워크를 사용하거나 공유기 설정에서 격리를 해제하세요                |
| 야외 환경이라 공유기가 없는 경우         | —                               | 스마트폰 핫스팟(2.4GHz)에 Pi와 노트북을 함께 연결하세요                          |

> preview 서버는 별도의 비밀번호 인증을 갖추고 있지 않습니다. 동일 네트워크 상의 사용자 누구나 영상 화면을 볼 수 있으므로, 공용 Wi-Fi 환경에서는 튜닝 완료 후 반드시 프로세스를 종료하세요.
